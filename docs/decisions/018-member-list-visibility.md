# 018 — Everyone in a workspace sees all members' names and emails

Date: 2026-10-15 · Status: Accepted (owner decision)

## Context
Phase 1 shows the member list to every role, including Read Only clients. That exposes agency
staff emails and other clients' emails to each client in a shared workspace.

## Decision
Every member of a workspace, Read Only included, sees every member's name and email.

## Alternatives considered
- **Names only for Read Only:** more private, but clients often need to contact the team directly.

## Consequences
- Agencies that need privacy between clients should put each client in its own workspace.
