# 032 — Triage is linked-repo issues not on the board

Date: 2026-11-10 · Status: Accepted (owner) · Builds on 009, 012

## Decision
- Triage lists open issues in the workspace's linked repos that are not on the board.
- Accept adds the issue to the board with a status. Decline closes it as not planned.
- Members and up see Triage. Read Only never does.

## Consequences
- Issues filed by outsiders on GitHub land in Triage without extra setup.
