# 031 — Linear features out of scope for v1

Date: 2026-11-10 · Status: Accepted (owner)

## Decision
Out of v1: SAML and SCIM, third-party integrations (Slack, Zendesk, Intercom, Sentry, Figma),
importers, Linear-style AI and coding agents, an MCP server, recurring issues, SLAs, triage rules,
initiatives across workspaces, insights dashboards, mobile apps, and "related" links.

## Consequences
- Roadmap Track E lists each, with tiers for what is in.
